# Supplementary Figure S2 provenance

`figure_s2_shap_summary_bar.png` was regenerated by `src/explainability/plot_shap_summary.py` from `results/phase7/shap_phase7_results.json`.

The 20 bars show the aggregate feature ranking for the leakage-corrected primary-tumor-only Full DeepSurv models. Bar color and labels report how many of the five outer folds included each feature in its fold-specific top 20. The stored Phase 7 mean pairwise top-20 Jaccard index is printed dynamically in the caption; the ranking is explicitly presented as unstable rather than as a reproducible biological signal.
